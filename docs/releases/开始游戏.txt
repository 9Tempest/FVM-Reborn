通关奖励
美味级（0）1 倍、火山级（1）1.25 倍、浮空级（2）1.5 倍、星际级（3）2 倍。以所选关卡 JSON 中已有的金币和各项材料数量为基数，分别乘倍率并向下取整；困难关卡原有的专属奖励保留，再应用本倍率。
普通关卡和蛋糕塔的首通、重复通关均适用，单人与双人一致。奖励难度在战斗开始时固定，中途改设置不改变本局奖励。选关预览与结算显示实际数量。
双方获得完整的共同奖励，不平分，也不按战斗火苗的 60% 分配。卡牌、装备、卡槽等解锁，任务领奖、Boss 战中掉落和金币拾取保持原规则；旧格式与实验室关卡保持原有结算。

发行验证状态：coop.4 的通关奖励原生测试 165/165、战斗桥接测试 53/53 已通过。完整公网 WSS 连续两场，以及本次 GitHub 发布包的实际下载、安装与启动仍待验收；结果和 SHA-256 以对应下载页为准。coop.3 的完整双客户端及发布包验收属于上一版记录，不代替本次验收。两台实际异地 Mac 的人工合作验收、Intel 完整游戏和全部关卡仍待验证。

异地合作
双方游戏请使用 coop.4。本版服务协议与运行代码未变，已安装 coop.3 合作服务的房主无需重装服务；更早的服务仍需按指南更新以支持独立卡组和菜单清屏。
房主的 Mac 需要安装兼容的合作服务，并保持电脑醒着、已登录、联网、游戏运行。房主服务安装与更新步骤见下方详细说明，队友无需安装服务。
房主：进入单人存档 → 双人异地合作 → 创建合作房间 → 复制邀请码，私下发给队友。
队友：双人异地合作 → 粘贴 → 加入合作房间。
两人都在线后，由房主点击「选择关卡」。随后两端分别从共享卡库选自己的卡组，各点「准备完成」，双方确认后自动开局。
新配置默认最高难度（难度值 3），已经明确保存的难度设置会保留。房主可以在游戏设置中调整，合作关卡使用房主选定的难度。
每人最多携带共同进度已解锁的卡槽数量，至少一张；两人可以选相同卡牌，同一人的卡组不能重复。已准备时先取消准备再修改卡组；房主可用「更换关卡」重新选关。
服务分别缓存每位玩家每一关的卡组；新关卡默认带入本人最近使用的卡组。再次进入时仍需双方确认，断线或服务重启也会清除准备状态。
开局时两人各点击空闲网格放置自己的角色。每人有独立卡牌冷却与火苗（出牌用的“阳光”资源）：初始和收取火苗双方各获原值的 60%，向下取整，每人最多 15,000；放卡只消耗自己的火苗。
共享战役进度、解锁与通关奖励。数字键 1–9 选自己的卡，右键取消，空格请求/取消自己的暂停。
通关后等待界面确认存档，再回合作房间选择下一关或退出。

跟随房主画面
队友可观看房主的主菜单、地图选关、蛋糕塔和实验室／合成屋，操作仍由房主完成。共享画面只来自游戏本身，不读取电脑桌面或其他应用。
菜单最高每秒 4 帧；返回合作大厅会清屏，独立选卡界面和战斗操作不会被菜单图像遮住，邀请码所在的大厅不共享。
战斗状态按约 33 毫秒间隔同步，房主确认操作后在下一游戏步优先更新，慢连接丢弃过时待发画面。实际公网延迟仍取决于网络和设备，33 毫秒不是操作延迟保证。

数据与恢复
合作数据保存在房主 Mac；单人存档独立保留。
短时断网会暂停并尝试恢复。房主游戏进程退出后，未结束战斗不能从中途恢复，但已保存的合作进度保留。
再次游玩选「重连上次的房间」。公网地址变化时，房主复制新重连码给原队友。
当前免费测试隧道地址可能变化，不是永久服务器地址。
