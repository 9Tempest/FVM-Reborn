FVM Reborn — macOS 双人异地合作测试版

安装
本次更新修复 macOS 下载隔离路径下的启动崩溃。
1. 把 FVM Reborn.app 拖入「应用程序」目录，打开即可。
2. 需要 macOS 13 或更新版本。支持 Apple Silicon 与 Intel 二进制；完整游戏目前已在 Apple Silicon 实测。
3. 客户端无需 GameMaker、Python 或开发账号。
4. 当前测试包为 ad-hoc 签名，尚未经过 Apple 公证。如系统无法验证开发者，请核对版本页及 SHA-256，按 Apple 官方说明决定是否打开：
   https://support.apple.com/102445

更新已有安装
先正常退出旧版，再替换并打开新版。macOS 14 或更新版本可能因临时签名变化，要求新版应用获得访问旧游戏数据的许可。请核对应用名称和下载来源，再通过系统提示决定是否允许。
等待这项许可时，游戏窗口可能尚未出现；拒绝许可可能使这次启动失败。这与首次打开未公证应用时的开发者验证提示是两个独立步骤。
本次更新保留原应用标识和存档位置。不要删除旧存档容器、修改容器元数据、移除下载隔离标记或关闭 Gatekeeper 来处理授权提示。

异地合作
房主的 Mac 需要先安装合作服务，并保持电脑醒着、联网、游戏运行。已为本次委托的房主 Mac 配置。
房主：进入单人存档 → 双人异地合作 → 创建合作房间 → 复制邀请码，私下发给队友。
队友：双人异地合作 → 粘贴 → 加入合作房间。
两人都在线后，由房主选择关卡与卡组；开局时两人各点击空闲网格放置自己的角色。
共享火苗、卡组与进度；数字键 1–9 选卡，右键取消，空格请求/取消自己的暂停。
通关后等待界面确认存档，再回合作房间或退出。

数据与恢复
合作数据保存在房主 Mac；单人存档独立保留。
短时断网会暂停并尝试恢复。房主游戏进程退出后，未结束战斗不能从中途恢复，但已保存的合作进度保留。
再次游玩选「重连上次的房间」。公网地址变化时，房主复制新重连码给原队友。
当前免费测试隧道地址可能变化，不是永久服务器地址。
